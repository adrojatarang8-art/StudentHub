Viva:
- What is JSON? A lightweight text format used for data exchange.
- What is AJAX? Data requests that update part of a page asynchronously.
- What is Fetch API? JavaScript interface for HTTP requests/responses.
- GET vs POST? GET retrieves; POST sends a request body for a write.
- Why prepared statements? Prevents SQL injection with bound values.
- Why HTTP 201? A new resource was created successfully.
- What is debouncing? Wait briefly after typing before starting a request.
- Why CSRF token? Protects authenticated write actions from forged requests.
