Short viva answers:
Q How are statistics loaded? A By SELECT COUNT(*) queries on MySQL tables.
Q How is admin-only access implemented? A auth_require_role('admin') verifies role and active status in MySQL on each request.
Q Why is nav alone insufficient? A Hidden links do not prevent unauthorized direct URLs; server enforces authorization.
Q What is audit_logs? A A database table recording admin action, target, actor and timestamp.
Q How is status toggle safe? A POST + CSRF + prepared UPDATE + transaction + audit entry, and self-deactivation safeguard.
Q How are monthly bars calculated? A COUNT registrations grouped by year-month of registered_at.
